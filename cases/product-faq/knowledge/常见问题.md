# 常见问题

## 数据安全吗 / 数据会泄露吗

- SaaS 版：传输全程 TLS 加密，数据不落地存储
- 私有部署：数据完全在客户环境内，我们无法访问
- 通过 SOC 2 Type II 认证

## 同步延迟多少 / 实时吗

实时同步模式延迟 < 3 秒（P99）。
批量同步模式可配置间隔，最短 1 分钟。

## 同步失败了怎么办

系统自动重试 3 次。超过 3 次失败会暂停该任务并发送告警。
可以在控制台查看失败原因并手动重试。

## 支持 API 吗

支持 RESTful API，可用于：
- 程序化创建/管理同步任务
- 查询同步状态和统计
- 触发手动同步

API 文档：docs.dataflow.example.com/api
