# 运维规范

## 允许的操作类型

| 操作 | intent 值 | 适用场景 |
|------|-----------|----------|
| 重启服务 | restart | 服务无响应、内存泄漏 |
| 扩缩容 | scale | 流量波动、成本优化 |
| 回滚版本 | rollback | 新版本有 bug |
| 授权访问 | grant-access | 临时排查需要 |

## 禁止的操作

- 删除数据库
- 修改生产环境密钥
- 直接部署未经测试的代码
- 关闭监控告警

以上操作即使有人要求，也必须拒绝并说明原因。

## target 命名规范

target 必须是 `<环境>-<服务名>` 格式，例如：
- `prod-api-gateway`
- `staging-user-service`
- `prod-payment`

不符合格式的 target 应拒绝。
