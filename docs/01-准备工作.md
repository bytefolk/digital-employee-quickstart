# 01 准备工作

## 先搞清楚你要装什么

整套东西分两半：

- **钉钉那一半**：在钉钉开放平台建一个"企业内部应用"，里面开一个机器人。
  钉钉会给你两串密钥（Client ID / Client Secret），相当于这个机器人的账号密码。
- **你电脑上这一半**：一个叫 Digital Employee 的程序，拿着那两串密钥连上钉钉，
  收到问题后查你的资料、问大模型、把答案发回钉钉。

## 需要装三个软件

### 1. Node.js（版本 20 或更高）

这是运行引擎的基础环境。

- 打开 <https://nodejs.org/>，下载 **20 LTS** 版本的安装包，一路下一步。
- 装完在终端里输入 `node -v`，看到 `v20.` 开头的版本号就对了。

### 2. git

用来下载引擎代码。

- Mac：装了 Xcode 命令行工具就自带，或者 `brew install git`。
- Windows：<https://git-scm.com/downloads> 下载安装包。
- Linux：`apt install git` 或 `yum install git`。

### 3. dws（钉钉工作空间命令行工具）

用来在钉钉开放平台建应用、拿密钥，省掉在网页后台点来点去。

安装方式见 <https://github.com/DingTalk-Real-AI/dingtalk-workspace-cli>。

装完在终端里输入 `dws --version` 应该能看到版本号。

> 不装 dws 也行，你可以在 <https://open-dev.dingtalk.com/> 网页上手动建应用，
> 然后把密钥手填进 `.env`。但用 dws 会快很多。

## 一条命令检查装好没

在项目目录里跑：

```bash
bash scripts/check-env.sh
```

它会逐项告诉你什么齐了什么缺，缺的会附上安装链接。

## 还需要两个"账号类"的东西

### 钉钉管理员账号

创建企业内部应用需要管理员权限。如果你不是管理员：

- 要么找 IT / 管理员同事帮你走这一步；
- 要么让他们给你临时开一个"应用开发"权限。

### 一个大模型的 API Key

数字员工需要一个大模型来组织语言。它支持 OpenAI 官方，也支持**任何兼容 OpenAI
接口**的服务（很多国内模型服务和自建网关都兼容）。

你需要问清楚三样东西：

| 要问的 | 长什么样 |
| --- | --- |
| 接口地址（baseUrl） | 类似 `https://xxx.com/v1` |
| 模型名称 | 类似 `gpt-4.1-mini` |
| API Key | 一长串字符，要保密 |

OpenAI 官方的 Key 在 <https://platform.openai.com/api-keys> 创建（需要先绑卡）。
