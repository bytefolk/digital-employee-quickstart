# 02 创建钉钉机器人

> [!WARNING]
> 本文是尚未交付的渠道部署方案历史草稿，不适用于公开 CLI `0.3.0`。仓库没有本文引用的
> 自动化脚本，当前 quickstart 也不能创建、发布或启动钉钉机器人。请勿按本文操作真实应用
> 或密钥。当前可执行路径见 [README.zh-CN.md](../README.zh-CN.md)。

这一步的目标：拿到 **Client ID** 和 **Client Secret** 两串密钥，并且让机器人
在钉钉里能被搜到。

## 第一步：登录钉钉

```bash
dws profile list
```

如果输出里 `profiles` 是空的 `[]`，说明还没登录。执行：

```bash
dws auth login --device
```

> **为什么要加 `--device`**：不加的话它会让浏览器跳到 `127.0.0.1` 的本机地址。
> 如果你是在服务器或容器里操作，你的浏览器访问不到那个地址，授权就回不来。
> 加 `--device` 会给你一个公网链接 + 一串授权码，用手机或任何浏览器都能完成。

它会打印类似这样的内容：

```
link: https://login.dingtalk.com/oauth2/device/verify.htm
authorization code: XXXX-XXXX
```

用**企业管理员账号**打开链接、输入授权码、确认授权。这条命令会一直等，最长
15 分钟。授权成功后会显示你的企业名和用户名。

再跑一次 `dws profile list` 确认，记下 `profile` 那一串 `corpId:userId`
（以后配置读取钉钉文档时会用到）。

## 第二步：一条命令建好应用和机器人

```bash
bash scripts/setup-dingtalk.sh "数字员工-答疑助手"
```

把引号里的名字换成你想要的。这条命令会：

1. 在你的企业里创建一个企业内部应用（**会二次确认，输入 `yes` 才真的执行**）；
2. 读取 Client ID / Client Secret，**直接写进 `.env` 文件**，不打印到屏幕上；
3. 把机器人配置成 Stream 模式（这样不需要公网服务器和回调地址）；
4. 把应用 ID 记到 `.dingtalk-app.json`，方便后面查状态。

看到 `机器人已配置为 Stream 模式，状态 ONLINE` 就成功了。

### 想手动在网页上建也可以

1. 登录 <https://open-dev.dingtalk.com/>（企业管理员账号）
2. 「应用开发」→「企业内部开发」→「创建应用」，选机器人类型
3. 进详情页 →「凭证与基础信息」，能看到 Client ID 和 Client Secret
4. 在「机器人」配置里，把「消息接收模式」选成 **Stream 模式**
5. 把两串密钥手填进项目根目录的 `.env` 文件

## 第三步：发布版本（关键！）

**应用建好了不等于能用。** 没发布的应用，机器人在钉钉搜索里是**完全搜不到**的。

```bash
bash scripts/publish-app.sh
```

第一次运行它会创建版本，然后告诉你需不需要审批。如果需要，它会列出候选审批人，
类似：

```
版本发布需要审批，请选择一位审批人（共 7 位）：
A. 张三（userId: 011166424028...）
B. 李四（userId: 040614592532...）
...
```

挑一个人，把他的 userId 传进去：

```bash
bash scripts/publish-app.sh 011166424028...
```

提交后状态会变成 `AUDIT`（审批中）。

## 第四步：催审批

这一步**不在你手上**。你选的那位审批人会在钉钉里收到审批通知，他点通过之后
机器人才会真正可用。

随时可以查状态：

```bash
bash scripts/app-status.sh
```

看到版本状态不再是 `AUDIT` 就说明通过了。

> **不想等审批也能先验证**：审批只影响"钉钉里能不能搜到机器人"，不影响问答能力
> 本身。你可以先做完 [03-启动数字员工.md](03-启动数字员工.md)，用命令行直接测
> 问答效果。

## 常见卡点

| 现象 | 原因 |
| --- | --- |
| 创建应用报权限错误 | 你的账号不是企业管理员，找 IT 同事 |
| 报 `机器人不存在，请先创建机器人` | 直接跑了 `robot enable`。必须先 `robot config` 创建，脚本已经处理好了顺序 |
| 钉钉里搜不到机器人 | 版本还在 `AUDIT`，等审批 |
| 只有你自己能看到机器人 | 可见范围里只有创建者，用 `dws dev app member add` 加人 |
