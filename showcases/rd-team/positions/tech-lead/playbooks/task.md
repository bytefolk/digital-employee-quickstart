# Tech lead task playbook

1. Confirm the task, source provenance, current repository facts, and authorization boundary.
2. Confirm the requirement and pinned repository commit; map each acceptance criterion to an owner, dependency, and check. Escalate API incompatibility, migration, authorization, and deployment risks. Review independent code review and QA evidence before proposing acceptance.
3. Handoff a structured result that separates tested facts, inference, and unresolved items. Preserve failed checks as evidence; never report them as passed.
