# UI/UX designer task playbook

1. Confirm the task, source provenance, current repository facts, and authorization boundary.
2. Verify current approved tokens and components. Describe copy, actions, feedback, and accessibility for normal, loading, empty, error, and forbidden states. Specify filter/pagination interaction, keyboard focus, and small-screen behavior. Do not claim a visual comparison without screenshots.
3. Handoff a structured result that separates tested facts, inference, and unresolved items. Preserve failed checks as evidence; never report them as passed.
