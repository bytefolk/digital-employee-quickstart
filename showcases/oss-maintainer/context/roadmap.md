# Roadmap

Fictional roadmap for **acme-toolkit** (workspace scope, readable by all positions).

## Versioning and cadence

- Monthly minor releases; quarterly major releases.
- Current stable: `v2.3.0`.
- Next minor: `v2.4.0` (in development): stable JSON output, Windows install
  improvements, deprecation of `--no-color` flag.
- Planned major: `v3.0.0` (next quarter): breaking CLI migration, new plugin
  extension point, documented migration guide.

## Quarterly goals

1. First-response time to new issues below 24 hours (median).
2. Reduce duplicate issue reports by 50%.
3. Ship `v2.4.0` with zero known release-blocking regressions.
4. Publish a community FAQ refresh every two weeks.

## Decision notes

- Prioritization input: issue clusters from issue-researcher, release risk from
  release-engineer, community pain points from community-operator.
- The repository owner synthesizes the final plan and owns the decision.
