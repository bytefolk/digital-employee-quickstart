# Release cadence

Fictional release rhythm for **acme-toolkit**.

- Monthly minor releases; quarterly major releases.
- Current stable: `v2.3.0`.
- Next minor: `v2.4.0` — stable JSON output, Windows install improvements,
  deprecation of `--no-color`.
- Planned major: `v3.0.0` — breaking CLI migration, plugin extension point,
  migration guide.
- A release can ship only when the release checklist is complete and no
  release-blocking regression is open.
